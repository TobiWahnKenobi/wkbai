# wkbai help

wkbai plays the real-time strategy game *Warrior Kings: Battles* with a new engine: modern graphics, larger maps, a new AI and many fixes, using the game files of your own copy.

## Where to start

- **New to the game?** Read [Your first skirmish](getting-started.md), then [the in-game screen](ui/hud/index.md).
- **The menus:** [every screen of the front end](ui/frontend/index.md) and [all options](options/index.md).
- **Playing:** [mouse, keys and camera](controls/index.md) and [the rules of the game](mechanics/index.md).
- **Your army and town:** [units](units/index.md), [buildings](buildings/index.md), [upgrades](upgrades/index.md) and [commands](commands/index.md).
- **This help itself:** [how to find help for anything on screen](using-help.md).
