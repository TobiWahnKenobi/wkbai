# Editors

The main menu's Editors button opens this screen. It holds wkbai's two editors.

![The Editors screen](shot:frontend-editors)

## Map Editor

Opens the [list of maps to edit](../map-editor.md). The chosen map opens paused with the editor: see [the map editor](../../editor/index.md) and [making a map](../../editor/make-a-map.md).

## AI General Editor

Opens the [AI General Editor](../general-editor.md), where you make AI Generals of your own with a portrait, a story and fourteen personality sliders.

## Back

Goes back to the [main menu](../main.md).

> wkbai: the original game has no Editors screen. wkbai puts its editors behind one button, so that the main menu has room for Help.
