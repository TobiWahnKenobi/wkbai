# Map Editor

Choose a map to change. It opens paused, with the map editor's window beside it: heights, ground textures, lakes and objects. What you make is saved as a new map in your user folder, and then appears in this list and in the skirmish lobby.

![The Map Editor's list of maps](shot:frontend-editlevels)

## The list of maps

Every map you can play: the skirmish maps as "4 Peaks (2)" (the name, then the number of players), then the Kingmaker campaign's provinces under their names, then the maps saved with the editor under their own names. The tutorials and the story levels aren't listed. Click a map to select it; a double click opens it.

## Edit

Opens the selected map in the editor. A double click on a map does the same.

## Back

Returns to the [main menu](main.md). Esc does the same.

## Tips

- In any single-player game, **F8** ([`mapEditor`](help:key/mapEditor)) switches the editor on and off too, so you can change a map while you play it.
- The editor's tools and keys are described in [the map editor](help:ui/hud/map-editor).
- The editor is not available in multiplayer.

> wkbai: the original game has no map editor in the game. Maps saved by wkbai's editor can still be read by the original, which sees the heights in whole steps and the first 63 lakes.
