# Controls

wkbai plays with the mouse and the keyboard together: the mouse selects and orders, the keys move the camera and reach things quickly.

## The short version

| To | Do |
|---|---|
| Select a unit or building | Left-click it |
| Select several | Drag a box round them, or Shift-click each |
| Select all of one kind nearby | Double-click one (some soldiers: a single click; see [Selecting](selection.md#all-of-a-kind)) |
| Give an order | Right-click where or what: the cursor shows which order |
| Queue an order after the present ones | Shift + right-click |
| Face a direction on arrival | Right-click the ground and drag the way to face |
| Move the camera | Arrow keys or W A S D; Shift goes faster |
| Turn the camera | Hold the middle mouse button and move the mouse |
| Raise or lower the camera | Mouse wheel |
| Jump to the selection | Space (again: the next unit) |
| Look somewhere on the map | Click the minimap |
| Store / recall a group | Ctrl+1 ... Ctrl+0 / 1 ... 0 (twice: go there) |
| Pause | P |
| Game menu | Esc |
