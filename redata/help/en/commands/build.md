# Build

<!-- gen:icon -->
![Build](game:interface/icons/sic_build_civic.tga)
<!-- /gen:icon -->

## Role

Opens the list of buildings this unit (or the Observatory) can put up. Pick one and place it on the map. See [placing buildings](../controls/building-placement.md).

## Offered by

<!-- gen:trained -->
- **Offered by:** [Arch Druid](../units/arch-druid.md), [High Priestess](../units/high-priestess.md), [Observatory](../buildings/observatory.md), [Peasant](../units/peasant.md), [Sapper](../units/sapper.md)
<!-- /gen:trained -->

## Needs

<!-- gen:needs -->
- Nothing: it is there whenever the unit or building is.
<!-- /gen:needs -->
