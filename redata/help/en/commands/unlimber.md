# Unlimber

<!-- gen:icon -->
![Unlimber](game:interface/icons/sic_unlimber.tga)
<!-- /gen:icon -->

## Role

Sets up a packed [Rocket Launcher](../units/rocket-launcher.md) so it can fire again. Set up, it can't move until you [Limber](limber.md) it.

## How it works

- **How:** press the button where you want the launcher to stand. The crew plays its setting-up animation once, then the launcher is ready, with [Fire Rocket](fire-rocket.md) and [Hold Fire](hold-fire.md) / [Fire at Will](fire-at-will.md).
- **Can't be interrupted:** an order you give while it is setting up waits until it is done.
- **Limits:** the button is hidden while the launcher is already setting up.
