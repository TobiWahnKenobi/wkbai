# Rules of the game

These pages explain how the game works underneath: where resources come from, why a unit hits harder from a hill, what makes your Manor grow into a Palace, and how a game is won. The controls are in [mouse, keys and camera](../controls/index.md), and each unit and building has its own page under [units](../units/index.md) and [buildings](../buildings/index.md).

Almost every rule here comes from the game set, the script files of *Warrior Kings: Battles* that wkbai runs unchanged. Numbers are the shipped game set's; a mod can change them. Where wkbai adds or changes something, the page says so in a **wkbai** note.
